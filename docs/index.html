FilamentStation

Firmware direkt im Browser flashen – ohne Installation, per USB-Kabel.

1. Firmware flashen

Gerät per USB mit diesem Computer verbinden, dann auf „Installieren“ klicken. Funktioniert in Chrome, Edge und Opera (Desktop) – diese Browser unterstützen die Web-Serial-API, die ESP Web Tools dafür benötigt. Firefox und Safari werden aktuell nicht unterstützt.

Dieser Browser unterstützt die Web-Serial-API nicht. Bitte mit Chrome, Edge oder Opera (Desktop) erneut versuchen. Diese Seite muss über HTTPS aufgerufen werden, damit geflasht werden kann.

Beim ersten Verbinden fragt der Browser, welcher serielle Port verwendet werden soll – das WT32-S3-Board meldet sich normalerweise als USB Serial/CP210x/CH340. Bei der Installation fragt ESP Web Tools, ob der komplette Flash-Speicher gelöscht werden soll: bei einer Erstinstallation auf leerer Hardware empfohlen, bei einem Update eines bereits eingerichteten Geräts nicht auswählen, damit WLAN-Zugangsdaten und Konfiguration erhalten bleiben (dafür eignet sich ohnehin meist eher die integrierte Update-Funktion unter Einstellungen → Firmware, siehe Benutzerhandbuch).

2. Bambu-Material-Mapping auf die SD-Karte kopieren

Diese Datei enthält die Zuordnung von Spoolman-Materialien zu Bambu-AMS-Profilen. Sie wird nicht mitgeflasht (sie gehört auf die SD-Karte, nicht in den internen Flash-Speicher des ESP32) – einmalig herunterladen und auf die SD-Karte kopieren:

bambu_materials.json herunterladen

Auf der SD-Karte ablegen unter: /config/bambu_materials.json. Fehlt die Datei, lehnt das Gerät jede Zuordnung eines AMS-Slots ab, bis sie entweder so kopiert oder über Einstellungen → Firmware → Material-Zuordnung aktualisieren direkt vom Gerät heruntergeladen wurde. Details: data/bambu-materials/README.md.
